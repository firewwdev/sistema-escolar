# ROTAS:

## Aluno

GET -> site.com/alunos - retorna lista de alunos
GET -> site.com/alunos/{id} - retorna um aluno específico
POST -> site.com/alunos - cadastra um novo aluno
PUT -> site.com/alunos/{id} - atualiza um aluno existente
DELETE -> site.com/alunos/{id} - deleta um aluno existente
